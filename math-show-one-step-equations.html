Solving One-Step Equations

Think of an equation like a balanced scale. Whatever you do to one side, you need to do to the other side to keep everything equal.

Visual 01 · The Balance

An equation has two equal sides.

The equal sign means that both sides have the same value.

x + 3
=
8
Both sides represent the same amount.
Our goal is to find the value of x.
Visual 02 · Undo

Undo what was done to x.

In x + 3 = 8, 3 was added to x. To get x alone, we use the opposite operation.

x + 3
=
8
↓
subtract 3 from BOTH sides
x
=
5
x = 5
The +3 was undone by −3.
Visual 03 · Keep it balanced

The same thing happens to both sides.

We cannot subtract 3 from only one side. That would change the balance.

x + 3
− 3
=
8
− 3
Left side: x + 3 − 3 = x
Right side: 8 − 3 = 5
Visual 04 · Multiplication

What if x is being multiplied?

Consider: 3x = 12. The 3 is multiplying x, so we use division to undo it.

3x
=
12
↓
divide BOTH sides by 3
x
=
4
x = 4
Visual 05 · The Opposite Operation

Every operation has an opposite.

The opposite operation helps us isolate the variable.

Think: "How do I undo it?"

Addition → Subtraction

Subtraction → Addition

Multiplication → Division

Division → Multiplication

Visual 06 · Try it

What should we do first?

Look at the equation and choose the operation that will undo what happened to x.

x + 7 = 12
Choose an operation.
x = 5
Visual Practice

Solve it.

What is the value of x?

x − 4 = 9

Remember it visually

Your goal is always the same: get the variable by itself.

1. Look at what is happening to x.
2. Choose the opposite operation.
3. Do it to BOTH sides.
4. Simplify.
5. Check your answer.
Example: x + 3 = 8 → x = 5
