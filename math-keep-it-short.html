Keep It Short

You don't need a whole lesson every time. Use this page when you just need a definition, formula, rule, or quick reminder.

Algebra Equations Inequalities Exponents Functions Formulas
x

Algebra

Variable

A letter or symbol representing an unknown value.

x = unknown

Coefficient

The number multiplied by a variable.

5x → 5

Constant

A number without a variable.

x + 7 → 7

Like Terms

Terms with the same variables and exponents.

3x + 2x = 5x

Distributive Property

Multiply the outside number by every term inside.

2(x + 3) = 2x + 6

Order of Operations

Parentheses → Exponents → Multiply/Divide → Add/Subtract.

PEMDAS
=

Equations

One-Step Equation

Undo the operation acting on the variable.

x + 4 = 9 → x = 5

Two-Step Equation

Undo addition/subtraction first, then multiplication/division.

2x + 4 = 10 → x = 3

Golden Rule

Whatever you do to one side, do to the other.

x + 2 = 7
<

Inequalities

Less Than

The first value is smaller.

3 < 5

Greater Than

The first value is larger.

7 > 4

Flip the Sign

Multiply or divide by a negative? Reverse the inequality.

−x > 4 → x < −4
²

Exponents

Exponent

Shows how many times a base is multiplied by itself.

2³ = 2 × 2 × 2

Zero Exponent

Any nonzero number raised to zero equals 1.

7⁰ = 1

Negative Exponent

Move the base to the denominator.

2⁻³ = 1/2³
f

Functions

Function

A relationship where each input has exactly one output.

f(x) = 2x + 1

Input

The value you put into a function.

x = 3

Output

The value produced by the function.

f(3) = 7

Quick Formulas

Useful formulas to keep nearby.

Slope
m = (y₂ − y₁) / (x₂ − x₁)
Slope-Intercept Form
y = mx + b
Distance
d = √((x₂−x₁)² + (y₂−y₁)²)
Pythagorean Theorem
a² + b² = c²
Quadratic Formula
x = (−b ± √(b²−4ac)) / 2a
Arithmetic Sequence
aₙ = a₁ + (n−1)d
