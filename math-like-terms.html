Combining
Like Terms

Once you know what coefficients and variables are, you can start putting similar terms together.

Lesson progress 3 of 5
Step 1 · Understand

What are like terms?

Like terms are terms that have the same variable part.

3x + 2x

Both terms contain x, so they are like terms. That means we can combine them.

3x + 2x = 5x
Think about it like objects.

3 apples + 2 apples = 5 apples. You can combine them because they're the same kind of thing. Algebra works the same way.

Step 2 · Compare

Same kind or different kind?

✓ Like terms

4x + 3x

Both terms contain x. They can be combined.

✕ Not like terms

4x + 3

One term has x and the other does not. They cannot be combined.

✓ Like terms

x + x

Both terms contain x.

✕ Not like terms

x + y

x and y are different variables.

Step 3 · The rule

Combine the coefficients.

When terms are alike, you add or subtract their coefficients.

4x + 3x = 7x
1
Find the like terms: 4x and 3x
2
Add the coefficients: 4 + 3 = 7
3
Keep the variable: 7x
