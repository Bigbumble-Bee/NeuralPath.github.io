Combining Like Terms

Think of like terms as things that belong in the same group. If they match, we can combine them.

Visual 01 · What is a term?

Start by looking at the pieces.

In the expression 3x + 2x + 5, there are three terms.

3x
+
2x
+
5
Each part separated by a + or − is a term.
Visual 02 · Find the groups

Like terms belong together.

Look at 3x + 2x + 5. The two x terms match because they both contain x.

SORT THE TERMS INTO THEIR GROUPS

x terms

3x 2x

Number terms

5

Notice how 3x and 2x can go together, while 5 stays separate.

Visual 03 · Combine

Now put the matching terms together.

We can combine the coefficients because the variable is the same.

3x + 2x = ?
5x
Visual 04 · Why does it work?

Think of x's as objects.

If you have 3 x's and then get 2 more x's, how many x's do you have?

x x x + x x = x x x x x
3 x's + 2 x's = 5 x's

That's why: 3x + 2x = 5x.

Visual 05 · Not everything matches

What about different variables?

We can only combine terms when their variable parts match.

3x + 2y
3x and 2y are not like terms. They have different variables.

So they stay: 3x + 2y

Remember it visually

Before combining anything, look at the variable part.

1. Find the terms.
2. Find the terms with matching variables.
3. Add or subtract their coefficients.
4. Keep the variable.
Example: 3x + 2x = 5x
